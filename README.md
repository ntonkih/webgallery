# Mod Gallery

Современная web-галерея с удобной админкой для управления фотографиями и категориями.

## Возможности

- 📁 Категории и фильтрация коллекции
- 💬 Комментарии к каждой фотографии
- 📝 Карточки с названием и описанием снимка
- 🛠️ Админ-панель с загрузкой изображений и регулировкой разрешения
- 🧠 Сохранение состояния в `localStorage`

## Как запустить

Проект — статическое приложение на чистом HTML/CSS/JS. Любой http-сервер подойдёт.

```bash
# пример c встроенным сервером Python
python -m http.server 5173
```

Откройте в браузере [http://localhost:5173](http://localhost:5173) и управляйте галереей.

## Структура

- `index.html` — каркас интерфейса
- `styles.css` — тема и компоненты в неоморфном стиле
- `scripts/main.js` — логика админки, галереи и работы с localStorage
- `DESIGN_CONCEPTS.md` — подборка визуальных концепций для выбора подходящего дизайна перед разработкой
